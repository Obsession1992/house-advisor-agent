# 🏠 Obsession · 购房决策助手

毒舌但真诚的"懂行朋友"，帮首次购房者判断二手房/老破小是否值得买。

## 功能特点

- 📸 **户型图分析**：上传户型图，分析格局硬伤
- 🪜 **楼层评估**：根据楼层、总层数给出专业建议
- 💰 **成本估算**：估算翻新费用，帮你算清入住底线
- 🎯 **决策建议**：综合评估，给出"谁适合买、谁别碰"的明确结论

## 安装运行

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 启动应用

```bash
streamlit run app.py
```

### 3. 访问

浏览器会自动打开 http://localhost:8501

## 使用方法

1. 在左侧填写信息：
   - 小区名称（必填）
   - 所在楼层/总楼层（必填）
   - 挂牌总价（必填）
   - 建筑年代/装修年份（选填）

2. 上传户型图图片

3. 点击"生成决策报告"

4. 查看完整的购房决策分析报告

## 技术栈

- Python 3.8+
- Streamlit（Web框架）
- Pillow（图片处理）
